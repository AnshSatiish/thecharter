# Diagrams

Diagrams for the report. Each one has an editable `.drawio` file (open it at [draw.io](https://app.diagrams.net/)), plus `.svg` and `.png` exports.

| Diagram | Files |
|---|---|
| Use case diagram | `use-case-diagram.*` |
| Architecture of the AI capability (semantic search) | `ai-capability-architecture.*` |
| Component diagram of the AI capability | `ai-component-diagram.*` |

After editing a `.drawio` file, export it again as PNG so the report picture matches.
