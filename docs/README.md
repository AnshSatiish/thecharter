# Documentation

| Folder | What is in it |
|---|---|
| `requirements/` | The partner's requirement documents: interactive map, admin and security, project summary |
| `architecture/diagrams/` | Use case diagram, AI capability architecture, AI component diagram, backend and Supabase database diagrams. Editable `.drawio` files here, PNG and SVG in `exports/` |
| `architecture/decisions/` | Short records of decisions the team made and why (one file each, numbered) |
| `reports/` | Technical reports submitted for the course |
| `security/` | PostgreSQL and Supabase security guide and checklist |
| `demo-uploads/` | Two ready-made synthetic projects (PDF, photos, form values) to upload when testing or demonstrating the admin form |

## The Figma prototype

The partner's original Figma Make prototype (React + Vite, mock data, about 140 files) used to live in `docs/reference/figma-app/`. It is not the product, so it was taken out of this branch to keep the repository focused. It is still on `main` before this restructure. To keep it permanently, move it into its own repository (for example `thecharter-figma-prototype`) or attach it as a zip to a GitHub release, and link it here.
